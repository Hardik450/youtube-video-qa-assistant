

# 🎓 YouTube QA Assistant

## 💡 Overview

**YouTube QA Assistant** is an intelligent agent designed to help users **learn deeply from YouTube videos**. Built using the LangChain framework and large language models, it:

* Extracts and processes the **transcript** of any public YouTube video.
* Lets users **ask questions** and receive meaningful answers.
* **Quizzes** users with generated questions and **grades** their responses.
* Tracks conversation history to enable **context-aware dialogue**.

Whether you're studying computer science (like CS50) or watching a history lecture, this assistant helps make your learning more interactive and measurable.

---

## ⚙️ Features

* 📄 Transcript extraction from YouTube videos
* 🧠 Question-answering with memory 
* 🤖 AI-generated quizzes based on video content
* ✅ Automated grading of user answers
* 💬 Continuous dialogue with chat history tracking

---

## 🛠️ Tech Stack

* `Python`
* `LangChain`
* `Google Gemini (2.0 flash)`
* `Chroma` for vector database
* `YouTubeTranscriptApi` for transcript extraction
* `PromptTemplate`, `ConversationalRetrievalChain`

---

## 📥 How It Works

1. User enters a YouTube URL.
2. The video’s **transcript** is fetched and split into chunks.
3. Each chunk is **embedded** and stored in a **vector store (Chroma)**.
4. A conversation interface allows:

   * Asking questions about the video.
   * Taking a 3-question quiz generated by the AI.
   * Receiving a **score** and **feedback** based on your responses.
